# Prompt 4 — File-Level Implementation Plan

Based on the approved API and React Native screen design, propose a detailed implementation plan.

Do not modify files yet.

Provide:

1. New Symfony files to create.
2. Existing Symfony files that must be modified (if any).
3. New React Native files to create.
4. TypeScript interface/type files needed.
5. React Native service files needed.
6. Navigation files required.
7. The recommended order of implementation.
8. A low-risk sequence that preserves the existing web application.

Constraints:

- Keep the web application fully functional.
- Limit modifications to the smallest possible set of files.
- Prefer additive changes over refactoring.

Return a step-by-step implementation plan.
