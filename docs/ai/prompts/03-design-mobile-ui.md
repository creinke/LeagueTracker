# Prompt 3 — Design React Native Screens

Based on the approved API design, propose the React Native mobile application screen structure.

Do not generate code yet.

Provide:

1. The list of screens required.
2. Navigation flow between screens.
3. Menu behavior before login and after login.
4. Which screen calls which API endpoint.
5. The minimal data required by each screen.
6. Which screens correspond directly to existing Twig templates.
7. Any recommended simplifications for mobile compared to the Twig UI.

Constraints:

- The mobile UI should mirror the logical structure of the web UI.
- The mobile UI does not need to match the exact HTML layout.
- Focus on usability and clarity for mobile devices.

Return the screen architecture only.
